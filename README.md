# InfoIP

A Python CLI tool that retrieves IP geolocation and network information using the IP-API service.

## Features
* Unlimited checks (As long you have an internet connection)
* Collects many informations about target IP
* Accepts hostnames
* Very fast

## Requirements
* Python 3.x
* ``curl_cffi`` library, do ``pip install curl_cffi`` if you don't have it
* Nothing else!

## Use
```bash
python infoip.py
```
enter the ip or hostname you want to know informations about the ip
